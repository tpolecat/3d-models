# Akro-Mils Bin Dividers

The Akro-Mils bin dividers [here](https://www.thingiverse.com/thing:2851931/files) work well, but I needed a different size for large screws and may end up making more.

- **AM_Bin_Insert_6b** is a 6-bin insert with six narrow half-length bins for screws up to about 60mm. Would probably also hold resistors and diodes.
